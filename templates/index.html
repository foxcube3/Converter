Universal File to Text Converter

Upload any file. Get plain text back. Supports PDF, DOCX, PPTX, XLSX, HTML, RTF, images (OCR), and audio/video (Whisper) when available.

Notes

  • For best OCR results on images, install Tesseract on your system.
  • Audio/video transcription uses Whisper and may download models on first run.
  • We return a downloadable .txt file with extracted text.
Built with Flask. This is a best-effort extractor using pure-Python libraries where possible.
